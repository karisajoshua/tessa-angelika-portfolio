# Tessa Angelika — Portfolio

Premium portfolio for **Tessa Angelika Mmaitsi**, Learning Experience Designer and Cybersecurity Practitioner.

## Design direction
Minimal, editorial and interaction-led. Near-black surfaces, cool grey typography and restrained blue-grey accents. Case studies are treated as learning journeys rather than résumé cards.

## Stack
React + TypeScript + Vite. No heavy UI framework; the visual system is bespoke.

## Local development
```bash
npm install
npm run dev
```

## Production
```bash
npm run build
```
